إدارة كتالوجات الموردين

ارفع ملف PDF، وسجّل بيانات المصدر، وتابع حالة المعالجة من مكان واحد. يسجل النظام الكتالوج، ويستخرج مرشحات المنتجات والموديلات والمواصفات والصور لمراجعتها بشريًا قبل أي اعتماد.

إضافة كتالوج جديد

يُحفظ الملف داخل مجلد DEV المخصص، ثم يسجل النظام بصمته الرقمية لمنع التكرار. لا ترفع كتالوجات سرية أو ملفات عمل حقيقية قبل اعتماد بيئة التشغيل.
